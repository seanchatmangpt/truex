# Summary: Claude Code: Best practices for agentic coding

**File:** Claude Code- Best practices for agentic coding.pdf

## 1. Main Thesis
Claude Code is a low-level, unopinionated CLI tool designed to integrate agentic AI directly into the engineering workflow. The paper outlines the best practices for maximizing agent autonomy, safety, and efficiency through environment tuning, multi-agent coordination, and iterative refinement.

## 2. Key Findings
- **Context is King:** The use of `CLAUDE.md` files provides persistent, project-specific law that Claude automatically pulls into context, significantly improving instruction adherence.
- **Workflow Isolation:** Using `git worktrees` and multiple repo checkouts allows parallel agent execution without state collision.
- **Verification via Redundancy:** A primary best practice is "Have one Claude write code; use another Claude to verify." This separation of context prevents "overfitting" and logical blindness.
- **Atomic Iteration:** Agents perform best when given a clear target (test case or visual mock) and allowed 2-3 iterations to refine the output.
- **Safe YOLO Mode:** For high-volume tasks like linting, agents can run uninterrupted in a containerized environment with bypassed permissions, provided network access is restricted.

### Admit / Refuse (The /allowed-tools Allowlist)

### Receipt (The PR/Commit)
The final "Receipt" is the Pull Request or Commit message generated by the agent, documenting the changes and the reasoning behind them.
