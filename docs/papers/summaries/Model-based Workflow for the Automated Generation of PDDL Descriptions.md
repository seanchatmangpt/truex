# Product Thesis: Automated Planning Authority via MBSE-to-PDDL Projection

The research in **"Model-based Workflow for the Automated Generation of PDDL Descriptions"** manufactures a deterministic boundary law for the automated derivation of planning authority from integrated system and product models. By **Projecting** structural and behavioral descriptions (SysML) into the Planning Domain Definition Language (PDDL), the system ensures that every **Attempt** at achieving a goal is grounded in the proven architecture of the **Substrate**.

## Accounting Domains (Conserved Authority)

1.  **System Structure (W1):** Conserved in the "Extended System Model" which captures components, interfaces, and relations.
2.  **Domain Predicates (W2):** Objects and predicates defined in Phase II serve as the static authority for all planning **Attempts**.
3.  **Action Logic (T1):** Preconditions and effects define the dynamic state transitions that the **Membrane** will **Admit**.
4.  **Goal Settlement (T2):** The "Extended Product Model" provides the initial and goal states required for the settlement of a planning task.

## Key Findings (Projections of Authority)

-   **Model-Based Workflow Projection:** Deploys a four-phase process to **Promote** legacy engineering models into executable PDDL descriptions: (I) Analysis, (II) Enrichment, (III) Provision, and (IV) Generation.
-   **PDDL Profile Membrane:** Implements a dedicated SysML profile that embeds planning-specific constructs (types, predicates, actions) directly into the model, acting as a structural **Membrane**.
-   **Automated Translation Promotion:** Utilizes Velocity Template Language (VTL) to autonomously **Project** domain-specific data into valid PDDL domain and problem files, eliminating manual encoding errors.
-   **Aircraft Assembly Validation:** Successfully **Admitted** a UR10 robotic collar-screwing process, proving that the workflow can manufacture robust plans for complex industrial operations.

## Relevance to Truex Post-Gall Operating Substrate

-   **Authority Extraction:** Demonstrates how the **Substrate** can autonomously **Promote** its static configuration (SysML) into a dynamic authority for AI planning.
-   **HookedConsequence Generation:** The automated PDDL generation maps to the manufacturing of **HookedConsequenceAttempts** from system-wide mandates.
-   **Membrane Enrichment:** Phase II (Enrichment) describes the process of "teaching" the **Membrane** about specific application-level invariants and actions.
-   **Object-Centric Evidence:** The resulting PDDL plans and solver actions serve as **Object-Centric Process Evidence**, proving the causal chain from initial state to goal completion.
