## 2. ORIGINAL PURPOSE
A single agent cannot solve complex organizational problems. `A2A` (Agent-to-Agent) was built to allow discrete LLM agents (e.g., Doctor, Auditor, Architect) to communicate, debate, and resolve tensions collaboratively. It provided the protocol for agents to pass context and delegate sub-tasks.
