## 2. ORIGINAL PURPOSE
Modern CPUs use branch prediction. In high-security, high-frequency environments, branch prediction causes timing attacks (side-channels) and latency spikes when the CPU guesses wrong. `bcinr` (Branchless C in Rust) was written to map abstract operational logic into O(1) constant-time mathematics, eliminating conditional branching entirely to ensure execution predictability.
