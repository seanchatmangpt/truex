## 2. ORIGINAL PURPOSE
LLMs are creative but notoriously bad at adhering to strict JSON schemas or process logic. DSPy provided prompt compilation, but it lacked enterprise workflow integration. `dspygen` was created to force LLMs to output structured, typed data (via `dslmodel`) so that their outputs could actually be used in production pipelines without breaking the system.
