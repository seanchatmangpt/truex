## 2. ORIGINAL PURPOSE
Before shifting to process geometries (YAWL/POWL) and object motion (OCEL), the architecture sought to define operational reality using Resource Description Framework (RDF) and semantic knowledge graphs. The massive `unrdf` monorepo was an attempt to map every business concept into triples and query them via SPARQL. It ultimately proved too static, missing the temporal "motion" aspect of enterprise systems.
